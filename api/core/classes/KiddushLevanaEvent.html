    Class KiddushLevanaEvent

    The latest time to recite Kiddush Levana (Sanctification of the Moon), calculated as halfway between one molad and the next, according to the Maharil (14 days, 18 hours, 22 minutes and 1.666 seconds after the molad).

    Generated by calendar when options.kiddushLevanaMaharil is true and options.location is provided:

    • When the time falls during the day (between alot hashachar 16.1° and tzeit 8.5°), it is moved back to alot hashachar that morning, the end of the last night on which Kiddush Levana can be said.
    • When the time falls during Shabbat or a Yom Tov, it is moved back to regular candle-lighting time before that Shabbat or Yom Tov.
    • The time is rounded down to the minute, never up.

    The memo lists the unadjusted earliest (3 and 7 days after the molad) and latest (Maharil and 15 days after the molad) times.

    • basename(): string

      Returns a simplified (untranslated) description for this event, suitable for grouping related events under a single name.

      For example, HolidayEvent strips qualifiers so that "Erev Pesach" → "Pesach" and "Sukkot III (CH''M)" → "Sukkot". For many events the basename and the event description are identical.

    getCategories

    • getCategories(): string[]

      Returns an array of category strings classifying this event, derived from its flags bitmask. The first element is the broad category (e.g. 'holiday', 'roshchodesh', 'parashat', 'omer'), followed by zero or more refinements (e.g. 'major', 'minor', 'fast').

      Returns ['unknown'] if no flag maps to a known category.

      Returns string[]

      Example

      import {Event, HDate, flags} from '@hebcal/core';
      new Event(new HDate(10, 'Tishrei', 5784), 'Yom Kippur', flags.MAJOR_FAST)
        .getCategories(); // ['holiday', 'major', 'fast']
      new Event(new HDate(1, 'Shvat', 5784), 'Rosh Chodesh Sh\'vat', flags.ROSH_CHODESH)
        .getCategories(); // ['roshchodesh']
